# Bank Management System (C++)

A console-based application written in C++ to demonstrate fundamental concepts of structured programming, data structures, and file handling.

---

## Features

### 1. Client Management
* Display the full list of registered clients.
* Add new client accounts.
* Update existing client details.
* Delete client records.
* Search for a client using their account number.

### 2. Transactions
* Deposit funds into a client account.
* Withdraw funds with validation against the account balance.
* View total balances across all accounts.

### 3. User Management and Permissions
* User authentication (Login System).
* Access control and permissions management using bitwise operations.
* Full user management functions (Add, Update, Delete, Find).

---

## Technical Details
* **Language:** C++
* **Storage:** Text-based file handling (`myfile.txt` and `usersfile.txt`).
* **Data Structures & Concepts:** Vectors, Structs, Enums, Bitwise Operations, and File Streams.

---

## Setup and Execution
1. Download the project files and open them in Microsoft Visual Studio or any standard C++ IDE.
2. Ensure that `myfile.txt` and `usersfile.txt` are placed in the root directory of the project.
3. Compile and run the application, then log in using your user credentials.
